# Blooming — 婚禮個人祝福頁（橄欖綠 × 小雛菊 × 簽名版）

## GitHub Pages 更新

1. 進入 https://github.com/1im8/b 並先備份原本檔案。
2. 上傳本資料夾的 `index.html`、`guests.js`、`signature.png` **三個檔案**到 repository 根目錄（與 README.md 同層），如已有同名檔就覆蓋。
3. Commit changes，等 GitHub Pages 部署完成，重新整理網站（必要時 Ctrl+Shift+R 清除快取）。
